# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по SemVer.

## [0.2.1] — 2026-11-20

### Добавлено

- iOS-платформа в каркасе: `flutter create --platforms=ios`, bundle id `ru.distiller.kalendarSamogon`, `ios/` исключён из анализатора.
- `docs/RELEASE.md` — чек-лист выпуска в RuStore, Google Play и App Store: иконки, подпись, keystore, версионирование, риски модерации.

### Изменено

- Решения по открытым вопросам зафиксированы в `PLAN.md`: обе платформы, публикация сразу под площадки, интеграция с колонной отложена.
- Этапы перестроены: M3 — выпуск в магазины, M4 — интеграция с Smart-Column-S3 (отложено). Добавлен параллельный iOS-трек в `docs/ROADMAP.md`.
- В стеке зафиксировано правило «никаких Android-only пакетов»; платформенные различия — за интерфейсом в `lib/platform/`.

## [0.2.0] — 2026-11-19

### Добавлено

- Каркас приложения M0: тёмная тема «погреб» (графит + янтарный акцент), русская локаль, нижняя навигация из пяти разделов — «Сегодня», «Календарь», «Партии», «Рецепты», «Ещё».
- Экраны-заглушки с осмысленными пустыми состояниями; раздел «Ещё» — список будущих функций.
- Виджет-тесты на запуск каркаса и переключение разделов.
- Локализованное имя приложения (`@string/app_name`) и версия 0.2.0.
- Версия в разделе «Ещё» читается из пакета (`package_info_plus`), а не хардкодится.

### Изменено

- Проект переехал на ASCII-путь `C:\distiller\KalendarSamogon`; путь с кириллицей оставлен джанкшеном. Причина: Dart AOT-компилятор на Windows не читает не-ASCII пути, `flutter build apk` падал с `Unable to read file ... app.dill`.
- Flutter 3.50: `package:flutter/material.dart` объявлен deprecated — перешли на `package:material_ui/material_ui.dart` и `cupertino_ui`.
- Добавлен `build-apk.cmd`: джанкшен, `pub get`, `analyze`, `test`, сборка APK одной командой.

## [0.1.0] — 2026-11-19

### Добавлено

- План проекта `PLAN.md`: концепция, сущности, экраны, стек, этапы, риски, открытые вопросы.
- `docs/CONTENT.md`: каталог контента — группы рецептов (брага, дистилляция, настойки, ликёры, выдержка, стили), справочники, 12 калькуляторов, статьи, глоссарий, шаблоны календаря.
- `docs/DATA_MODEL.md`: схема локальной БД (drift/SQLite), перечисления, связи, быстрые запросы, миграции и бэкап.
- `docs/UX.md`: навигация, экраны, ключевые сценарии, напоминания, доступность.
- `docs/ROADMAP.md`: этапы M0–M4 с критериями готовности.
- `docs/CONVENTIONS.md`: правила версионирования, проверок, коммитов и контента.
- Проверено окружение: Android Studio 2025.2.2 (JBR 21), Android SDK (platforms 33/34/36), AVD `Medium_Phone_API_36.1`; Flutter SDK отсутствовал — установка начата.
