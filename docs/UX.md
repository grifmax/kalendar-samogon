# Экраны и сценарии

Material 3, тёмная тема по умолчанию («погреб»: графит + янтарный акцент), светлая — опция. Крупные элементы под палец, минимум модальных диалогов, всё важное — в одно-два касания.

## Навигация

Нижняя панель: **Сегодня · Календарь · Партии · Рецепты · Ещё**

## 1. Сегодня (главный экран)

- Блок «Просрочено» (красный) — что не сделано.
- Блок «Сегодня» — чек-лист событий с чекбоксами, свайп «сделано / перенести на завтра».
- Блок «Скоро» — 3–7 дней вперёд.
- Карточки активных партий: название, день процесса, прогресс-полоса, «следующий шаг через N дней», крепость.
- Если пусто — онбординг: «Заведите первую партию» + 3 готовых рецепта в один тап.

## 2. Календарь

- Переключатель месяц / неделя / список.
- В ячейке — до 3 цветных точек по типу процесса (брага, перегон, настойка, бочка, дегустация) + «+N».
- Тап по дню — список событий, тап по событию — карточка с действиями.
- Фильтры-чипы по типу и по партии.
- Пустое состояние: подсказка, что события появляются из партий.

## 3. Партии

- Список с группировкой по статусу, поиск, фильтры.
- Карточка: рецепт, день N, объём/крепость, где стоит, следующее действие.
- FAB «Новая партия»: выбрать рецепт → указать дату старта, объём, ёмкость → приложение генерирует события.

### Карточка партии (ключевой экран)

Вкладки/секции:
1. **Таймлайн** — все шаги рецепта: сделано / сейчас / впереди, с датами.
2. **Замеры** — список + график (плотность и температура на одной оси времени), кнопка «Добавить замер».
3. **Перегонки** — прогоны с фракциями, итог: сколько голов/тела/хвостов, выход АС.
4. **Заметки и фото** — свободный журнал.
5. **Дегустации** — оценки и выводы.
- Действия в меню: «Слить в тару», «Залить в бочку», «Розлив», «Завершить», «Дублировать партию», «Поделиться карточкой».

## 4. Рецепты

- Каталог: вкладки по типу, поиск, чипы (быстро/долго, сахар/зерно/фрукты, бочка/щепа), избранное.
- Карточка рецепта: состав таблицей (с пересчётом под мой объём), шаги, признаки готовности, типичные ошибки, источник.
- Кнопка «Запустить партию» — переносит рецепт в календарь.
- «Свой рецепт» — форма: состав с автодополнением из справочника, шаги с длительностью и температурой.

## 5. Ещё

- **Калькуляторы** — хаб из 12 плиток, каждый открывается как отдельный экран с полями и результатом; последние расчёты сохраняются.
- **Склад/погреб** — тара и что в ней: бочки, бутыли, банки; остаток в литрах и в АС; «что готово к розливу».
- **Дегустации** — общий журнал с оценками и поиском «что понравилось».
- **Оборудование** — профили аппаратов, подключение Smart-Column-S3 (адрес, проверка связи, импорт истории).
- **Справочник** — статьи, глоссарий, таблицы (поиск по всем).
- **Настройки** — единицы (л/мл, %/proof), тема, время напоминаний по умолчанию, бэкап/восстановление, экспорт CSV, о приложении.

## Сценарии, которые обязаны работать без интернета и без «Ага, сейчас»

1. Поставил брагу в 23:40 — 30 секунд: выбрал рецепт, объём, дата, сохранил; календарь заполнился сам.
2. Утром пришло напоминание «проверить плотность» — открыл, ввёл 1.040, увидел прогноз «готово через ~4 дня».
3. Перегон: завёл прогон, вбил банки по 0.5 л с крепостью — приложение посчитало головы/тело/хвосты и выход АС.
4. Залил в бочку — появились доливки каждые 30 дней и дегустации через 1/3/6/12 мес.
5. Через год открыл приложение — вся история на месте, потому что бэкап был с первого дня.

## Напоминания

- Канал «Процессы» (высокий приоритет) и «Мягкие напоминания».
- Время по умолчанию — 10:00 локально, настраивается на событие.
- Точные будильники где можно, иначе — неточные + бейдж; в приложении всегда виден список «просрочено».
- Действия из уведомления: «Сделано», «Отложить на день», «Открыть партию».

## Доступность и мелочи

- Минимальная зона нажатия 48 dp, контраст ≥ 4.5:1, поддержка масштаба шрифта до 130%.
- Все списки — с пустыми состояниями и понятной причиной, почему пусто.
- Никаких блокирующих сплэшей и обязательных аккаунтов.
