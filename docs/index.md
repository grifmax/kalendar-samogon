# Календарь самогонщика

Журнал домашнего винокура для Android: рецепты, партии, календарь браг, настоек и
выдержки, замеры, калькуляторы, статистика.

Приложение работает офлайн: нет аккаунта, рекламы и сбора данных.

- [Политика конфиденциальности](PRIVACY.html)
- [Описание для магазинов](STORE_LISTING.html)
- [Правила проекта](CONVENTIONS.html)
- [Исходный код](https://github.com/grifmax/kalendar-samogon)

**18+.** Приложение — журнал и справочник для совершеннолетних. Оно не продаёт
алкоголь и не заменяет соблюдение закона. Чрезмерное употребление алкоголя
вредит вашему здоровью.
